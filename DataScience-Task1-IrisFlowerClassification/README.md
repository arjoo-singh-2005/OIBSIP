# Iris Flower Classification

## Project Objective
The objective of this project is to train machine learning classification models to identify the species of an iris flower using its physical measurements.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Models Used
- K-Nearest Neighbors (KNN)
- Logistic Regression

## Dataset
Iris dataset from Scikit-learn.
